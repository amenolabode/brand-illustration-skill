# Reference systems

Short case notes on how top brands built their illustration systems, so directions aren't anchored on any one example.
Each lists the family, what is documented and the lesson. Verify before quoting to a client; sources move.

| Brand | Family | Documented facts | Lesson |
|---|---|---|---|
| **Klarna** (Animade, in-product) | Brand device + flat | Built from the curvature of Klarna's typography and its italic moments, extrapolated from palette, photography, tone and typeface; delivered with a style guide so the team could extend it | Derive illustration from the brand's own type and shapes, not only from an outside source world |
| **Klarna** (2024 refresh) | Art direction / photo + motion | In-house refresh around "magic from the mundane"; pink kept, palette extended; new art direction and motion | Illustration may be the minor voice; know when photography leads |
| **Monzo** (2022, Ragged Edge + Ola Dobrzyńska) | Expressive line / character | Brief: personality, movement, energy; avoid flat geometry and generic people; 90 illustrations; global (no £, no text, no UK-only references) | Commission a hand; write global-use rules |
| **Cash App** (Buck, 2D) | Editorial line | Thousands of sketches → hundreds of illustrations; tone set by word pairs ("charming but not cute", "simple but not plain", "specific but not complicated"); influenced by editorial magazine drawings; mapped to in-app surfaces | Use "X but not Y" pairs to fence tone; map style to surfaces |
| **Cash App** (Buck, Evergreen 3D) | Soft 3D | Reimagined spatial system; 3D library delivered with source files; 3D brand guidelines | 3D needs a rig and source files, not just renders |
| **Revolut** | Soft 3D | Hiring material describes simple 3D illustrations and animations to help users understand product actions | 3D can be functional explanation, not only decoration |
| **Mailchimp** (Buck, The Cube) | Brand device + mascot | Cube = illustration mark that unfolds to tell any story; transitional device between type and UI; complements Freddie rather than competing | Add a device for product capability without killing existing warmth |
| **Duolingo** | Flat + character | Few vector shapes, clear silhouettes, fewest details needed, exaggeration, white negative space; vector for scale and speed | Shape-language rules let many artists stay consistent |
| **Atlassian** | Tiered: flat spot, low-fi UI, ambient pattern, collage | Spot for empty/error/celebration; low-fi UI (simple shapes, sharp corners, mostly grey) for onboarding; ambient pattern for backgrounds; collage only for marketing; don't overuse | Choose illustration type by touchpoint |
| **Robinhood** (2024, Porto Rocha) | Technical | Technical illustration inspired by financial graphs; black/white with neon accent; modular layout | A category's own notation can be the source |
| **Dropbox** | Expressive line / mixed | Illustration library extended with small icon-like "Smalls" and cropped "Heroes" (Animade) | Plan formats (smalls, heroes) as well as style |
| **Cowrywise** (Dá Design Studio) | Pattern-led + oblique 3D | Colourful guilloché-inspired patterns; 3D language for "looking at things from all sides" | Pattern works when the source means something; see `cowrywise-example.md` |

## How to use this

- Don't copy any of these. Use them to widen the option space and to name the family clearly.
- When the user names a brand they admire, find its row and extract the **lesson**, not the look.
- Add rows as you research new brands, with documented facts separated from your observations.
